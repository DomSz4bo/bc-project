I need a software system to control a smart package locker for a residential building.

A customer should be able to walk up to the screen and enter their pickup code. The system needs to check the database to see if the code is valid and find out which locker door their package is in. 

If the package has been sitting in the locker for more than 3 days, there is a late fee. In that case, the system must prompt the user to pay the fee using a connected credit card terminal. 

Once the code is verified (and any required fees are paid), the system should physically pop open the correct locker door and update the database to mark the package as "Picked Up". We also need to handle cases where the code is wrong, the credit card is declined, or the locker door gets jammed and fails to open.
